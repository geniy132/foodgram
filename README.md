# foodgram

### Проект "Foodgram" 
 
### 1. Общее описание:  
C помощью данного проекта пользователи могут могут находить и создавать
кулинарные рецепты.
В проекте также настроена система подписок на автора, избранное (рецепты) и реализована возможность просмотреть и скачать (файл формата .txt) список покупок (ингредиенты и их количество в списке добавленных рецептах).  
Цель проекта - разнообразить кулинарные предпочтения пользователей. 
 
### 2. Установка и запуск: 
Клонировать репозиторий и перейти в него в командной строке: 
 
``` 
git clone https://github.com/geniy132/foodgram.git 
``` 
 
``` 
cd foodgram
``` 
 
Cоздать и активировать виртуальное окружение (для Windows): 
 
``` 
python -m venv env 
``` 
 
``` 
source venv/Scripts/activate 
``` 
 
Установить зависимости из файла requirements.txt: 
``` 
cd backend
``` 
 
``` 
pip install -r requirements.txt 
``` 
 
Выполнить миграции: 
 
``` 
python manage.py migrate 
``` 

Заполнить базу данных списком ингредиентов: 
 
``` 
python manage.py load_ingredients
```

Запустить backend проекта: 
 
``` 
python manage.py runserver 
``` 

Запустить frontend проекта (потребуется установить дополнительное ПО - [Docker Desktop](https://docs.docker.com/desktop/setup/install/windows-install/) (для Windows) и инструмент запуска Linux на Windows - [WSL](https://learn.microsoft.com/ru-ru/windows/wsl/install) (пропустить, если уже установлено и настроено)):

``` 
cd ..
``` 
 
``` 
cd infra
``` 

``` 
docker-compose up
``` 
### 3. Использование: 
Функциональная составляющая проекта реализуется посредство отправки запросов на эндпоинты. 
[Документация](http://localhost/api/docs/) к проекту доступна после запуска frontend-а. 
 
### 4. Структура проекта: 
Проект построен из трех основных приложений: recipes (отвечает за основную логику работы проекта),
api (отвечает за предоставление интерфейса для взаимодействия между различными программными компонентами)
и users (отвечает за пользовательскую модель).
 
### 5. Технологии: 
Проект построен, как REST API, для взаимодействия с приложениями посредством  
HTTP-методов и предоставляет ответы в формате JSON. Для работы проекта используются сторонние 
[библиотеки](backend/requirements.txt). Логика проекта реализована на Python v3.12.7 посредством 
использования библиотек веб-фреймворка Django. API реализован посредством библитеки  
djangorestframework. Для системы аутенфикации и регистрации пользователей использована библиотека djoser.
