# foodgram

### Проект "Foodgram" 
 
### 1. Общее описание:  
C помощью данного проекта пользователи могут могут находить и создавать кулинарные рецепты.
В проекте также настроена система подписок на автора, избранное (рецепты) и реализована возможность просмотреть и скачать (файл формата .txt) список покупок (ингредиенты и их количество в списке добавленных рецептах).
Цель проекта - разнообразить кулинарные предпочтения пользователей. 

Проект доступен по адресу: -
 
### 2. Установка и запуск: 
Клонировать репозиторий и перейти в него в командной строке: 
 
``` 
git clone https://github.com/geniy132/foodgram.git 
``` 
 
``` 
cd foodgram
``` 
 
Cоздать и активировать виртуальное окружение (для Windows): 
 
``` 
python -m venv venv 
``` 
 
``` 
source venv/Scripts/activate 
``` 

Установить зависимости из файла requirements.txt:

```
pip install -r requirements.txt
```

Установить перемнные окружения (заполнить файл [.env.example](.env.example) своими данными и переименуйте его (удалите ".example" из имени)).

Запустить проект (потребуется установить дополнительное ПО - [Docker Desktop](https://docs.docker.com/desktop/setup/install/windows-install/) (для Windows) и инструмент запуска Linux на Windows - [WSL](https://learn.microsoft.com/ru-ru/windows/wsl/install) (пропустить, если уже установлено и настроено)):
```
docker compose -f docker-compose.yml up 
```

В новом окне терминала примените миграции и заполните БД:
```
docker compose -f docker-compose.yml exec backend python manage.py migrate
```

```
docker compose -f docker-compose.yml exec backend python manage.py load_ingredients
```

Запустить проект - перейдите на локальную страницу проекта [Foodgram](http://127.0.0.1:8000/).

### 3. Использование: 
Функциональная составляющая проекта реализуется посредство отправки запросов на эндпоинты. 
[Документация](http://127.0.0.1:8000/api/docs/) к проекту доступна после запуска. 
 
### 4. Структура проекта: 
Проект построен из трех основных приложений: recipes (отвечает за основную логику работы проекта), api (отвечает за предоставление интерфейса для взаимодействия между различными программными компонентами) и users (отвечает за пользовательскую модель).
 
### 5. Технологии: 
Проект построен, как REST API, для взаимодействия с приложениями посредством HTTP-методов и предоставляет ответы в формате JSON. Для работы проекта используются сторонние [библиотеки](backend/requirements.txt). Логика проекта реализована на Python v3.12.7 посредством использования библиотек веб-фреймворка Django. API реализован посредством библитеки djangorestframework. Для системы аутенфикации и регистрации пользователей использована библиотека djoser.
